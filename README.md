# 🐟 Feeding Frenzy 2: Shipwreck Showdown (HTML5 Canvas Remake)

Một dự án tái hiện tựa game huyền thoại **"Cá lớn nuốt cá bé" (Feeding Frenzy 2)** chạy trực tiếp trên trình duyệt web, được viết bằng HTML5 Canvas, JavaScript thuần và Web Audio API.

![Feeding Frenzy 2 Banner](https://img.shields.io/badge/Game-HTML5_Canvas-blue) ![License](https://img.shields.io/badge/License-MIT-green)

---

### 🎮 Tính năng nổi bật (Features)
- **60 Màn chơi & Bản đồ Quần đảo (Island Map Progression):** Hệ thống mở khóa từng màn chơi tuần tự từ Level 1 đến Level 60 với trạng thái lưu tự động.
- **Tự động tiến hóa 6 loài cá (Hero Evolution):** Trải nghiệm lần lượt 6 nhân vật quen thuộc: *Boris (Cá Bướm)*, *Layla (Cá Bò)*, *Edie (Cá Vảy Chân)*, *Peter (Cá Chim)*, *Harry (Cá Sú Mì)* và *Goliath (Cá Mập Trắng)*.
- **Giao diện & UI chuẩn nguyên bản:** Menu bảng gỗ, thanh HUD Growth, combo "FRENZY!", Score và thanh Ability.
- **Cơ chế Pause/Settings trực quan:** Tạm dừng game, điều chỉnh âm thanh, chơi lại hoặc về Menu chính dễ dàng ngay trên màn hình.
- **Hiệu ứng & Âm thanh sống động:** Xử lý tách nền sprite cá tự động, hoạt ảnh cá mở miệng đớp mồi cùng âm thanh "Chomp!" bằng Web Audio API.

---

### 🛠️ Công nghệ sử dụng (Tech Stack)
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Graphics:** HTML5 2D Canvas API
- **Audio:** Web Audio API (procedural sound generation)
